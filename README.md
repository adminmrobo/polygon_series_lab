# 그릴 수 있는 등비급수 — 정다각형 속 나선의 넓이

정다각형의 각 변의 중점을 이으면 안에 같은 모양의 작은 정다각형이 생깁니다. 이것을 끝없이 되풀이하며 모서리 조각을 칠한 나선 하나로 **등비수열 → 로그 눈금 → 등비급수 → 단위 읽기**를 차례로 보는 데이터시각화 연구실 해설입니다. 연구실 스킬 ai-lab-explainer v1.19("낮의 연구실", 흰 배경)와 비전공자판 ai-lab-explainer-plain v1.5(원리 먼저 교수법 P1~P7 내장)를 따릅니다. **조수 하루와 인턴 시아가 서로 묻고 답하며** 나아가고, 박사·초파리 연구원·주판봇·인턴 모아·방청석 X1~X3가 돕습니다.

- 사이트: https://adminmrobo.github.io/polygon_series_lab/
- 글 · 안상선 ((주)M-Robo 대표) · [저자 소개](https://adminmrobo.github.io/who_am_i/who_am_i.html)

| 단계 | 내용 | 시각화 포인트 |
|---|---|---|
| ① 중점 | 변의 중점을 이으면 넓이 r = cos²(π/n)배인 닮은꼴 | 버블 차트: 반지름이 아니라 넓이로 |
| ② 등비수열 | 넓이 1, r, r², … | 로그 눈금이면 곧은 직선 |
| ③ 등비급수 | 부분합이 1/(1 − r)에 멈춤, 99% 도달 조각 수 | 누적 그래프 + 끝값 점선 + 기준선 |
| ④ 단위 | S는 "첫 조각 = 1" 단위, 실제 넓이는 언제나 도형의 **1/n** | 이중 축 대신 두 차트로 |
| AI 판단 코너 | AI가 쓴 보고 문장을 단위·가정·상식으로 점검 | 계산이 맞아도 결론은 틀릴 수 있음 |
| 대결 | 포스터를 가장 많이 칠하려면 몇 각형? → 초파리 승 (F), 심판 시아 | 축 제목 읽기 |
| 연습 | 정팔각형으로 r·S·실제 몫 계산 + 해석 문장 고르기 (자동 채점) | 보고서 한 줄 쓰기 |

## 원자료와 검산

- 바탕: matharium 인포그래픽 「A regular polygon is a geometric series you can draw」(사용자 제공 이미지, 원 게시물 주소·게시일 미확인). 원본 그림은 저장소에 넣지 않았고, 도형과 차트는 모두 새로 그렸습니다.
- 원자료의 r·S 예시 네 가지(삼각형 1/4·4/3, 정사각형 1/2·2, 정오각형 (3 + √5)/8·≈2.89, 정육각형 3/4·4)는 검산해 맞습니다.
- 고친 곳 두 가지: "꼭짓점을 잇는다" → "변의 중점을 잇는다"(꼭짓점끼리 이으면 n에 따라 다른 도형이 되거나, 정오각형처럼 닮은꼴이어도 넓이비가 약 0.146으로 달라짐), "색칠한 넓이 = 1/(1 − cos²(π/n))" → "첫 조각을 1로 둔 크기 S". 실제 넓이 = 도형의 1/n은 이 페이지에서 더한 결론입니다.
- 검산: `python3 code/check_numbers.py` (도형을 실제로 100단계 쪼개 넓이를 잼)
